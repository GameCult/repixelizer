Pipeline

How the machine behaves

A short machine, full of ugly truths and no unnecessary ceremony.

1. Read the grid Infer one plausible lattice from autocorrelation instead of wandering through a candidate carnival all day.
2. Pick the size Probe a tiny size check up front so the solver does not begin life already standing in a pothole.
3. Let the field work Run one displacement field with enough leash to recover detail instead of compensating with decorative nonsense.

Self-hosters can still go straight to the app. Hosted mode just gets a front door instead of making everyone trip over raw controls immediately.
