Repixelizer

Take fake pixel art, force it onto a real lattice, then inspect the crime scene frame by frame.

How To Use It

1. Drop an input on the right or choose a file.

2. Leave size blank to let the machine search, or pin width and height if you already know the lattice.

3. Run it, watch the status panel for the active stage, then patch the output by hand if the machine gets cute.
